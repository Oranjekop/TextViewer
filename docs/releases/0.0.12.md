# TextViewer v0.0.12

- 工具栏增加“撤销”和“重做”按钮，使用 SVG 图标，支持简体中文和英文提示。
- 点击按钮可撤销当前标签的编辑或恢复已撤销的编辑；继续编辑后清除原来的重做分支。
- 没有相应编辑记录时按钮自动置灰，后台操作和确认对话框期间禁止执行。
- 与编辑菜单及 Ctrl+Z / Ctrl+Y 共用当前标签的撤销记录，切换标签后自动更新。
- 窄窗口收紧工具栏间距，保留按钮尺寸、代码格式显示及原有窗口最小宽度。
- 保留 v0.0.11 新增的编辑菜单、行操作、文本整理与转换功能。
- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的单文件便携 ZIP。
