# TextViewer v0.0.20

- 工具栏新增文本对比按钮，可直接选择两个已打开的标签进行只读对比。
- 修复空标签关闭后“未命名”编号持续递增的问题，复用已释放的编号，保留其他标签的名称和状态。
- 底栏新增 Unicode 字符数统计，包含空格与换行。大文件使用后台分块统计、编辑防抖和快照缓存，避免稳定显示时重复扫描全文。
- 新增 macOS 适配：Command 快捷键、原生菜单、字体和设置记忆、文件打开与拖放；新建文档默认使用 LF，已有文件保留原保存格式。
- macOS 提供一个 Universal `.pkg` 安装包，同时包含 Apple Silicon 和 Intel，无需选择架构；安装到 `/Applications`，升级时替换旧应用。
- macOS 设置支持文件类型登记和 Finder 快速操作，提供六类、81 种常用格式及最高 1024px 的文件图标；在线更新下载并校验同一个 Universal 安装包。
- Windows 继续提供自动选择 x64 / ARM64 的合并安装包，以及对应架构的单文件便携 ZIP。所有安装包和便携包均列入 SHA-256 清单。
- macOS 安装包尚未使用 Developer ID 签名和公证；Finder 快速操作可按需在系统设置中启用，默认打开方式由 Finder“显示简介”设置。
