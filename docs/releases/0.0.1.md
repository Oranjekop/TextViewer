# TextViewer v0.0.1

首个正式版本，使用 Go / MyGo 开发的 Windows 原生文本查看编辑器。

## 功能

- 大文本打开、编辑、保存、撤销和重做；支持 UTF-8、UTF-16 BOM 和 GB18030。
- 自动换行、字号调整、异步查找、替换与全部替换。
- 按文件名识别代码格式，可手动切换语言；提供语法高亮、等宽字体、缩进线和括号匹配。
- SVG 工具栏、浅色/深色主题及生图设计的应用图标。
- 启动时后台检查更新，也可从“设置 → 检查更新”手动检查；下载安装前确认，下载后验证 SHA-256，安装前处理未保存文档。
- Windows 11 新版右键命令“在 TextViewer 中打开”。

## 安装

推荐下载 `TextViewer-Setup-0.0.1-windows.exe`，安装时自动选择本机 x64 / ARM64 程序，提供开始菜单入口及卸载功能。也提供对应架构的完整便携 ZIP。

右键扩展使用自签名 MSIX 身份包。首次从应用设置启用时，需要用户决定是否信任所附的签名证书，并亲自处理 Windows 管理员确认。程序不会自动信任证书、开启开发者模式或更改 TXT 默认打开方式。该自签名不代表 Windows 公共发行商认证；新版首层菜单安装仍需在用户批准信任后验收。

公开文件的 SHA-256 位于 `SHA256SUMS.txt`。初版安装程序未使用商业 Authenticode 证书签名。

CI 尚未配置持久发行签名证书，每次构建的右键身份包使用独立的自签名；更新后启用右键可能需要再次确认信任。

## 验证与限制

- 包含按版本标签自动构建、单元测试、静态检查、原生右键命令测试，以及隔离安装/卸载验收。
- 本机约 100 MiB 多行 TXT / JSON 样本已做打开、编辑、搜索、保存及渲染性能测试；这不是任意 2 GiB 或极长单行文件的性能保证。
- x64 安装在实际 Windows 环境测试；ARM64 产物交叉编译并检查架构，尚未在真实 ARM64 设备安装。
