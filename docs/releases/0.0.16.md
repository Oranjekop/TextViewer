# TextViewer v0.0.16

- 所有文件的编辑区均支持滚轮纵向平滑滚动，普通文本、日志、代码和 Markdown 使用一致的滚动体验。
- 连续滚轮输入可累积滚动距离，反向滚动从当前显示位置立即转向，并按实际文档布局限制滚动范围。
- 保留触控板、系统惯性、拖动滚动条和键盘定位的原有响应；编辑、选择或切换标签时停止未完成的滚动动画。
- 遵循 Windows 的减少动画设置，关闭系统动画时直接滚动到目标位置，滚动结束后不持续请求动画帧。
- Markdown 预览跟随编辑区的每一帧滚动，在右侧滚动时及时交接控制，避免两侧争抢滚动位置。
- 平滑滚动不额外扫描或复制全文，不改变正文、选区、焦点及撤销记录；提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的单文件便携 ZIP。
