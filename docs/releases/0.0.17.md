# TextViewer v0.0.17

- 修复 Markdown 分栏高度超出窗口的问题，滚动条和状态栏可在窗口底部完整显示。
- 修复拖动预览滚动条时编辑区未完成的平滑滚动抢回控制的问题，两侧可正确交接滚动控制。
- 修复预览拖到底后编辑区没有跟随到文末的问题，两侧滚动条可连续同步至顶部和底部。
- 改善调整窗口、字号、缩放比例及打开查找栏后的滚动同步，兼容自动换行和横向滚动条。
- 保留大文件预览的截断边界，预览末尾对应已预览的源码位置，不会把完整文档的后续内容拉回；同步不额外扫描或复制全文，不改变正文、选区及撤销记录。
- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的单文件便携 ZIP。
