# TextViewer v0.0.9

## Windows 图标与右键菜单

- 为右键打开时使用的身份包补齐 16–256 px 的透明、去底板和浅色去底板图标，以及资源索引，处理任务栏图标出现蓝色背景的问题。
- Windows 10 使用当前用户的原生右键菜单，无需安装 MSIX 或信任证书；Windows 11 保留新版右键菜单。
- 设置中的选项统一为“Windows 右键菜单”，README 同步说明 Windows 10 / Windows 11 的使用方式。

## 启动与单实例

- 改用 Windows 原生单实例通信，避免首次启动探测旧套接字；再次点击开始菜单入口会激活已有窗口。
- 修正文件转交时丢失首个文件参数的问题，支持空白启动以及带空格、中文的文件路径。
- 图标加载失败时保留编辑器窗口，较早 Windows 10 版本回退到可用的图标 API。
- 通过连续启动、单文件转交、关闭后重启和 30 秒运行检查。旧版自行关闭的问题本机未复现，此次对启动和错误处理作了加固。

## 单文件分发

- 脚本、原生右键 DLL、MSIX 身份包及证书全部内置于 EXE。便携 ZIP 只包含一个 `TextViewer.exe`，可直接移动和运行。
- 正常启动不解包、不执行注册脚本；配置系统集成时，才向 `%LOCALAPPDATA%\TextViewer\Integration` 释放所需资源。
- 全新安装目录仅包含 `TextViewer.exe` 与 `Uninstall.exe`。提供自动选择 x64 / ARM64 的合并安装包。

## 升级提示

- 升级保留文件关联、右键菜单和界面设置的启用选择。
- Windows 11 的旧身份包缺少新版运行模型或图标索引时，需要在设置中重新保存右键选项，并按提示确认新的签名信任；安装包不会自动导入证书。
- Windows 10 右键注册已完成隔离测试，尚未在 Windows 10 实机验收。
