# TextViewer v0.0.15

- Markdown 编辑区与右侧预览支持双向滚动同步，滚动任一侧时，另一侧按内容位置跟随。
- 根据 Markdown 块的源位置与预览布局对齐，在段落内部平滑估算位置，适配标题、列表、引用和代码块的不同高度。
- 调整分栏宽度、字体或显示缩放，以及编辑后刷新预览时，会重新对齐；关闭后重新打开预览，按当前编辑位置跟随。
- 避免两侧互相触发滚动；大文件预览达到截断范围后，左侧仍可继续编辑全文，不会被拉回。
- 滚动同步复用编辑器行索引和预览位置，不额外扫描或复制全文，也不改变正文、选区、焦点及撤销记录。
- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的单文件便携 ZIP。
