# TextViewer v0.0.19

- 新增文本对比：在“编辑 → 文本对比”选择两个已打开的标签，左右只读显示文本快照，按行高亮新增和删除，支持上一处 / 下一处差异及 Shift+F3 / F3。关闭对比后保留原标签、选区、撤销记录和保存格式。
- 新增 Base64 编码 / 解码，位于“编辑 → 转换”：处理精确选区，支持多选区；没有选区时处理全文。解码支持标准及 URL-safe Base64、缺省填充和格式空白，无效输入或非 UTF-8 结果不会修改原文。
- Base64 操作支持后台计算、取消和一次撤销；修正解码 CRLF 文本时的多选区位置计算，保留文件的保存编码及换行格式。输入合计上限 32 MiB。
- 文本对比在后台准备，每侧上限 8 MiB、50,000 行；稳定显示时复用差异结果，超限提示而不截断原文。
- 新增 Ctrl+点击网页 URL，在默认浏览器中打开 HTTP、HTTPS 或 www 链接；对大文本采用有界局部识别。
- 补齐新增功能的中英文界面及小窗口、高 DPI、原文保护和撤销回归。
- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的单文件便携 ZIP。
