# TextViewer v0.0.10

## 查找与替换

- 查找栏增加“正则”和“转义字符”选项，支持 `\n`、`\r`、`\t`、`\\` 以及十六进制和 Unicode 转义。
- 正则替换支持 `$0`、`$1`、`${1}`、`${name}` 和 `$$`，可用于跨行查找、分组提取及文本整理。
- `^` / `$` 默认匹配行首和行尾，`(?s)` 可让 `.` 跨行；正则使用 Go 语法，不支持环视和查找表达式中的反向引用。
- 保留普通字面查找；两个选项都关闭时，反斜杠和美元符号按原文处理。
- 查找在后台流式读取大文件，不为正则匹配复制全文或收集全部结果。替换保留编码与所选换行格式，应用前可取消，应用后可一次撤销。
- 修正连续查找中的行首、行尾、单词边界和零宽度匹配处理；表达式错误直接显示在查找栏，保留正文。

## 中英文界面

- 增加简体中文和英文，默认跟随系统语言；不支持的系统语言使用英文。
- 在“设置 → 界面语言”中选择“跟随系统 / 简体中文 / English”，保存后立即生效，并记住选择。
- 编辑区右键菜单及其“选择”“转换”子菜单与界面语言一致，修复剪切、复制等项目中英混杂的问题。
- 菜单、工具栏、查找替换、字体、代码格式、设置、更新和应用提示同步翻译。
- 切换界面语言保留已打开标签、正文、光标、撤销记录、编码和换行格式；取消设置或保存失败时保留原语言。

## Windows 安装包

- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的单文件便携 ZIP。
- 保留已有字体、系统集成和其他界面设置。
