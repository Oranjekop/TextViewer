# TextViewer v0.0.6

## 多文件与标签

- 支持一次选择、拖入或从启动参数打开多个文件，使用标签切换，保留各文件的光标、滚动位置、撤销记录和保存格式。
- 使用 MyGo 官方标签组件，以文字选中态和底部强调线显示当前文件；支持关闭按钮、标签列表、横向滚动及窗口缩放后的定位。
- 已打开的文件会定位到已有标签；多个大文件按顺序在后台载入，标签切换复用编辑状态，不重新读取或复制正文。
- 支持 Ctrl+W 关闭标签、Ctrl+Tab / Ctrl+Shift+Tab 切换标签；关闭、退出或安装更新前检查所有未保存的文件。
- Windows 11 新版右键支持同时打开多个文件，较大选择按命令行长度分批传入，不执行所选脚本。

## 保存与更新

- 工具栏增加“另存为”按钮，支持 Ctrl+Shift+S，保留当前目录、扩展名、编码和换行格式；另存为后当前标签指向新文件。
- 拒绝另存为覆盖其他已打开标签的文件；在保存确认或文件选择期间收到的新文件请求会排队处理。
- 设置内检查更新时保持弹窗与未保存选项，显示等待和检查结果；发现新版后可在原页选择安装。
- 文件菜单、编码和换行格式等下拉按钮增加箭头。

## 框架

- MyGo 升级至 v0.7.4，并核对标签在浅色、深色、窄窗口及不同缩放比例下的布局。

## 安装与更新

- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的完整便携包。
- 旧版本可从“设置 → 检查更新”获取；升级保留文件关联与右键菜单的启用选择。
- 安装程序不会自动导入证书，文件关联注册保留已有默认打开方式。
