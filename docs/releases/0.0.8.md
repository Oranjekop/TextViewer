# TextViewer v0.0.8

## 图标修复

- 修复右键打开文件时标题栏和任务栏图标失真的问题，覆盖已关联文件与未知扩展名。
- 统一使用 EXE 内预先生成的多尺寸应用图标，与双击打开时的图标资源保持一致。
- 按显示器 DPI 选择图标尺寸，避免直接缩小大尺寸 PNG 导致小图标细节丢失；DPI 改变时重新加载合适尺寸。
- 普通移动、缩放窗口和打开文件不重复加载图标，窗口关闭时释放图标资源。

## 安装与更新

- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的完整便携包。
- 旧版本可从“设置 → 检查更新”获取；升级保留文件关联与右键菜单的启用选择。
