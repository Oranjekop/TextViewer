# TextViewer v0.0.3

## 新增

- 注册 81 种常用文本、Markdown、代码、数据、配置和脚本格式，可在 Windows“打开方式”和“默认应用”中选择 TextViewer。
- 增加六类配套文件图标，由生图工具设计透明母版，提供 16–256 px 共十个尺寸；图标内置于程序。
- 增加“设置 → 文件关联”，支持注册常用格式、移除关联及打开 Windows 默认应用设置。
- 打开文件对话框使用统一的格式清单，涵盖 TXT、LOG、MD、JSON、CSV、YAML、TOML、INI 及常用代码和脚本文件。

## 安装与兼容

- 安装时自动注册常用文件格式，卸载时移除当前安装拥有的关联；保留已有默认程序、其他编辑器入口和用户文件。
- 需要双击使用 TextViewer 并显示配套图标时，请在 Windows 默认应用设置中选择相应格式。PS1、BAT、CMD、SH 等脚本也只进入编辑器打开。
- 便携版注册后将完整程序和图标固定到本地目录，移动原解压目录后仍可使用。
- 文件关联独立于新版右键身份包的签名信任；保留旧版 TXT、LOG 的 MSIX 关联声明，并更新其文件图标。
- 修复从 PowerShell 7 等环境启动时，Windows PowerShell 继承不兼容模块目录导致注册失败的问题。
- 提供自动选择 x64 / ARM64 的合并安装包及两个架构的完整便携包。旧版本可以通过“设置 → 检查更新”获取此版本。

## 验证与性能

- 新增隔离注册表测试，覆盖默认程序与默认哈希不变、重复注册、升级迁移、移除退役格式、保留其他处理程序及旧副本不能移除新版关联。
- 增加 Windows 原生图标载入检查，覆盖六类图标的全部十个尺寸；安装验收检查 EXE 内置图标与生成产物一致。
- 关联和图标写入仅在安装、注册或移除时执行，不参与文档载入、编辑或每帧绘制。
- 安装与关联测试使用隔离目录和注册表；资源管理器图标目视验收及 ARM64 真机安装尚未完成。

新版右键身份包仍使用自签名，更新后启用右键可能需要用户再次确认信任并处理 Windows 管理员确认。安装程序不会自动导入证书。
