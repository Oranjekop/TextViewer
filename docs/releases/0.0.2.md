# TextViewer v0.0.2

## 修复

- 修复 Windows 11 26H2 自定义右键菜单关闭“应用扩展”子菜单后，“在 TextViewer 中打开”只在旧菜单中显示的问题。
- 添加菜单时单独启用 TextViewer 的主菜单项，保留其他应用及系统菜单的显示设置。重复添加已经注册的菜单同样可以恢复显示。
- 添加或移除菜单后通知资源管理器刷新，无需强制结束资源管理器。

## 安装与更新

- 提供 x64 / ARM64 自动选择架构的合并安装包及两个架构的完整便携包。
- 旧版本可以通过“设置 → 检查更新”获取此版本。
- 右键身份包使用自签名；更新后启用右键可能需要用户再次确认信任，并亲自处理 Windows 管理员确认。安装程序不会自动导入证书。
- 安装后如菜单仍未显示，从 TextViewer“设置”再次选择“添加到 Windows 11 新版右键菜单”。

## 验证与性能

- 新增独立注册表中的显示配置回归测试，覆盖隐藏子菜单、重复添加及保留其他设置，并纳入自动构建。
- 增加通过系统实际 COM 注册激活命令的检查模式，验证标题、图标及文件筛选。
- 显示配置仅在添加菜单时更新；展开右键时仍由原生扩展处理，不启动编辑器或读取文本正文。
- 新版菜单的目视验收及 ARM64 真机安装尚未完成。
