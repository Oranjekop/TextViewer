# TextViewer v0.0.11

## 编辑菜单

- 工具栏增加“编辑”下拉按钮，使用 SVG 图标和下拉箭头，与现有按钮保持一致。
- 集中提供撤销、重做、剪切、复制、粘贴、删除、全选、查找、替换、转到行和 JSON 格式化。
- 增加当前行选择、匹配项选择、扩大和缩小选择、上下添加光标及按行拆分选择。
- 保留原有快捷键，复制行使用 Alt+Shift+Down，Ctrl+D 继续选择下一匹配。

## 行编辑与文本整理

- 支持复制行、删除行、上下移动、上下插入空行、合并行、缩进和减少缩进。
- 支持升序、降序和忽略大小写排序、反转行序及删除重复行。
- 支持清理行首、行尾或两端空白，删除空行或仅含空白的行。
- 支持制表符转空格及行首空格转制表符，使用当前代码格式的制表符宽度。
- 排序、去重和空白处理有选区时作用于所选的完整行，没有选区时处理全文；选区终点位于下一行行首时，不包含下一行。

## 文本转换与代码操作

- 支持大写、小写、单词首字母大写、反转所选文本大小写，以及 snake_case、kebab-case、camelCase、PascalCase 转换。
- 大小写和命名转换处理选中文本；没有选区时处理光标所在单词。
- 提供行注释与块注释，根据当前代码格式启用支持的操作。
- 编辑菜单完整适配简体中文和英文。

## 大文本与撤销

- 排序、去重、空白处理及所选文本转换在后台执行，应用前可取消，完成后可一次撤销。
- 保留原编码、换行格式和其他标签的编辑状态；无变化时不增加撤销记录。
- 去重仅为唯一行建立索引，多选区位置使用前缀差值和二分查找，减少重复行及大量选区的处理开销。
- 大范围整理仍需要文本副本、结果和行索引，内存开销随处理范围和行数增加。

## Windows 安装包

- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的单文件便携 ZIP。
- 保留已有字体、语言、系统集成和其他界面设置。
