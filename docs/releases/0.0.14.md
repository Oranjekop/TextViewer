# TextViewer v0.0.14

- 新增 Markdown 右侧预览，支持标题、强调、列表、任务列表、表格、引用、链接和代码高亮，预览文字可选择和复制。
- Markdown 文件默认显示预览，可通过标签栏右侧的分栏按钮或 Ctrl+Shift+V 打开、关闭；拖动中间分隔线可调整宽度。
- 各标签独立保留本次打开期间的预览开关、分栏比例和滚动位置，切换预览不改变正文、选区或撤销记录。
- 编辑停止 250 ms 后自动刷新，预览字体、字号和深浅主题跟随应用；手动选择 Markdown 代码格式也可启用预览。
- 大文件最多预览开头 64 KiB、1,000 行，并限制渲染复杂度，超出时显示截断提示；关闭预览停止解析正文，左侧仍可编辑完整文件。
- 支持文档目录中的本地图片，另存为后更新相对路径基准；图片数量、文件大小、累计像素和并发解码均有限制，远程图片保留描述文字。
- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的单文件便携 ZIP。
