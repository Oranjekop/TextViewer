# TextViewer v0.0.5

## 设置

- 右上角设置改为弹窗，集中调整外观、启动更新检查、文件关联和 Windows 11 右键菜单。
- 文件关联和右键菜单分别使用复选框控制：勾选后保存启用，取消勾选后保存移除；点击“取消”不改变系统设置。
- 记住启用与关闭选择，后续升级不会重新开启已关闭的功能；首次安装由用户在设置中选择是否启用。

## 修复

- 修复升级后资源管理器右键仍指向旧版程序的问题，重新绑定到当前版本，并核对 Windows 实际注册的程序目录。
- 补齐稀疏包需要从程序目录读取的视觉资源，修复包图标显示为通用图标的问题。
- 安装升级及保存设置后清理不再使用的旧程序副本，保留仍被引用、正在运行、被占用或包含用户新增文件的目录。
- 右键重注册失败时恢复原程序目录；无关的部署错误不会先移除正常注册。
- 系统集成状态只在打开设置时后台读取，不增加文件载入或每帧重绘中的系统查询。

## 安装与更新

- 提供自动选择 x64 / ARM64 的合并安装包和两个架构的完整便携包，旧版本可从“设置 → 检查更新”获取。
- 升级可复用已注册的受信任右键身份，避免因为新签名尚未受信任而继续打开旧程序。首次启用或缺少可复用身份时，仍可能需要确认签名信任及 Windows 管理员提示。
- 安装程序不会自动导入证书；文件关联注册保留已有默认打开方式。
