# TextViewer v0.0.7

## 图标修复

- 为主窗口显式设置应用图标，修复从右键打开未关联文件时可能显示错误任务栏图标的问题。
- 在图标设置完成后显示窗口，避免启动时先出现默认图标。
- 使用 256×256 原始 PNG，按当前显示器的 DPI 生成大小图标；DPI 改变时重新从原图生成，避免放大小尺寸图标造成模糊。
- 图标仅在窗口初始化或 DPI 改变时生成，普通移动、缩放窗口和打开文件不重复生成。

## 安装与更新

- 提供自动选择 x64 / ARM64 的合并安装包，以及两个架构的完整便携包。
- 旧版本可从“设置 → 检查更新”获取；升级保留文件关联与右键菜单的启用选择。
